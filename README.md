# Calculadora Python

Aplicação simples de linha de comando em Python, criada apenas para fins pedagógicos. Permite realizar as quatro operações matemáticas básicas: soma, subtração, multiplicação e divisão.

## Pré-requisitos

- Python 3.8 ou superior instalado

Verifique a versão instalada:

```
python3 --version
```

## Como executar localmente

1. Clone o repositório

```
git clone <url-do-repositorio>
cd calculadora-python
```

2. Execute a aplicação

```
python3 calculadora.py
```

3. Siga o menu exibido no terminal, escolhendo a operação desejada e informando os dois números solicitados.

## Exemplo de uso

```
=== Calculadora ===
1 - Soma
2 - Subtração
3 - Multiplicação
4 - Divisão
0 - Sair
Escolha uma opção: 1
Digite o primeiro número: 10
Digite o segundo número: 5
Soma = 15.0
```
